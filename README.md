# Лабораторна робота №5. Тестування навантаження комп'ютерної мережі

**Дисципліна:** Тестування та контроль якості (QA) вбудованих систем
**Виконала:** Павлюк В.О., група ІА-32 (КПІ ім. Ігоря Сікорського, ФІОТ)

## Тестове оточення

| Вузол | Роль |
|---|---|
| PC1 (server), 10.0.0.1 | сервер iperf 2.1.9 (`iperf -s`, `iperf -s -u`) |
| PC2 (client), 10.0.0.10 | клієнт iperf 2.1.9, gnuplot 6.0 |

Ubuntu 24.04 LTS, VirtualBox, внутрішня мережа `intnet`.
